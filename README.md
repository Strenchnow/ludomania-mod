# Ludomania

Мод для **Minecraft 1.21.1 + NeoForge 21.1.x**: крутки, слоты, колесо удачи и стриковые триппы.
Всё на виртуальных фишках — реальных ставок нет.

## Состав

- **Казино-фишка** — валюта. 1 изумруд → 8 фишек (и обратно).
- **Слот-машина «Крутобан»** — три барабана, ставки x1/x10/x100.
  Три в ряд платят до x50, пара возвращает ставку, три семёрки — ДЖЕКПОТ.
- **Колесо удачи** — 8 секторов (x2, x3, x5, x10, 0, TRIP, JP), ставки x1/x5/x25.
- **Лутбокс «Сюрприз»** — одноразовая крутка в руке: фишки, изумруды, алмазы,
  золотые яблоки, порции триппа, пустышки и фейк-джекпот.
- **Система стриков** — серии побед/поражений хранятся на игроке (переживают смерть)
  и вызывают эффекты: скорость, прыгучесть, ночное зрение, удача (победы);
  тошнота, замедление, тьма (поражения); от x5 и выше — психоделический
  оверлей на экране, джекпот — полный погружной трипп с левитацией.

## Сборка

Требуется **JDK 21**.

```bash
# если gradlew не исполняемый (например, после распаковки архива):
chmod +x gradlew
./gradlew build
```

Готовый jar: `build/libs/ludomania-1.0.0.jar` — кидаешь в папку `mods`.
Для запуска клиента с модом: `./gradlew runClient`.

Важно: сборка качает NeoForge и Minecraft-артефакты с `maven.neoforged.net` —
это должно быть доступно из твоей сети.

## Настройка выплат

Все шансы и множители — в коде, прямо и понятно:

- `game/SlotMachineLogic.java` — символы, веса, множители (раздел SlotSymbol).
- `game/WheelLogic.java` — секторы колеса.
- `game/LootboxLogic.java` — таблица наград лутбокса (пороги в процентах).
- `streak/StreakEffects.java` — пороги стриков и эффекты.

## Структура

- `blocks/` — блоки автоматов (открывают меню).
- `menus/` — контейнеры меню (предметных слотов нет: ставки идут через инвентарь).
- `screens/` — клиентские GUI с анимацией барабанов и колеса.
- `net/` — пакеты: запрос крутки → серверный честный ролл → результат.
- `streak/` — данные стриков (NeoForge attachment) и эффекты.
- `client/` — оверлей триппа поверх экрана.
